# HTML Notes

HTML stands for **HyperText Markup Language**. It is used to create the structure of web pages. Every website uses HTML in some way because HTML tells the browser what content should appear on the page.

HTML is not a programming language. It is a markup language. It uses tags to define different parts of a web page, such as headings, paragraphs, links, images, lists, tables, forms, and sections.

## Brief History of HTML

HTML was created by **Tim Berners-Lee** in 1991. It was first made to share documents on the World Wide Web. Later, HTML improved with many versions. Today, **HTML5** is the modern version of HTML.

HTML5 supports:

- Audio and video
- Better form controls
- Semantic tags
- Graphics using canvas and SVG
- Mobile-friendly web pages
- Cleaner website structure

## Why HTML is Important

HTML is important because it is the foundation of web development. Without HTML, a web page cannot have proper structure.

HTML is useful because:

- It creates the basic structure of websites.
- It is easy to learn for beginners.
- It works with CSS for styling.
- It works with JavaScript for interactivity.
- It supports images, videos, links, tables, and forms.
- It is used in almost every website.

## Basic HTML Document Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>Hello HTML</h1>
    <p>This is a paragraph.</p>
</body>
</html>
```

## Common HTML Tags

| Tag | Use |
| --- | --- |
| `<html>` | Root element of an HTML page |
| `<head>` | Contains page information |
| `<title>` | Sets browser tab title |
| `<body>` | Contains visible page content |
| `<h1>` to `<h6>` | Creates headings |
| `<p>` | Creates paragraphs |
| `<a>` | Creates links |
| `<img>` | Adds images |
| `<br>` | Adds a line break |
| `<hr>` | Adds a horizontal line |
| `<ul>` | Creates an unordered list |
| `<ol>` | Creates an ordered list |
| `<li>` | Creates list items |
| `<table>` | Creates a table |
| `<form>` | Creates a form |
| `<input>` | Creates input fields |
| `<button>` | Creates a button |
| `<pre>` | Preserves spaces and line breaks |
| `<code>` | Displays code text |
| `<blockquote>` | Displays a quotation |

## HTML Entities

HTML entities are used to display reserved characters and special symbols.

Examples:

| Entity | Output |
| --- | --- |
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&amp;` | `&` |
| `&copy;` | copyright symbol |
| `&nbsp;` | non-breaking space |

Example:

```html
&lt;p&gt;This is a paragraph&lt;/p&gt;
```

This displays:

```text
<p>This is a paragraph</p>
```

## Semantic HTML

Semantic HTML means using tags that clearly describe their meaning.

Examples of semantic tags:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

Semantic tags make web pages easier to read, easier to maintain, and better for search engines and accessibility.

## 20 HTML Viva Questions and Answers

### 1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

### 2. Is HTML a programming language?

No, HTML is not a programming language. It is a markup language.

### 3. Who created HTML?

HTML was created by Tim Berners-Lee in 1991.

### 4. What is the latest version of HTML?

The latest major version is HTML5.

### 5. What is the use of `<!DOCTYPE html>`?

It tells the browser that the document is written in HTML5.

### 6. What is the use of the `<html>` tag?

The `<html>` tag is the root element of an HTML document.

### 7. What is the difference between `<head>` and `<body>`?

The `<head>` contains information about the page, while the `<body>` contains visible content.

### 8. What is the use of the `<title>` tag?

The `<title>` tag sets the title shown in the browser tab.

### 9. What are HTML elements?

HTML elements are made using tags and content. Example: `<p>Hello</p>`.

### 10. What are HTML attributes?

Attributes provide extra information about an element. Example: `<a href="https://example.com">Visit</a>`.

### 11. What is the use of the `<a>` tag?

The `<a>` tag is used to create hyperlinks.

### 12. What is the use of the `<img>` tag?

The `<img>` tag is used to display images on a web page.

### 13. What is the difference between ordered and unordered lists?

An ordered list uses numbers, while an unordered list uses bullets.

### 14. What is the use of the `<br>` tag?

The `<br>` tag adds a line break.

### 15. What is the use of the `<pre>` tag?

The `<pre>` tag displays text exactly as written, including spaces and line breaks.

### 16. What is the use of the `<code>` tag?

The `<code>` tag is used to display computer code.

### 17. What are HTML entities?

HTML entities are special codes used to display reserved characters and symbols.

### 18. What is semantic HTML?

Semantic HTML uses meaningful tags like `<header>`, `<main>`, `<section>`, and `<footer>`.

### 19. What is the use of forms in HTML?

Forms are used to collect user input, such as name, email, password, and messages.

### 20. How do HTML, CSS, and JavaScript work together?

HTML creates the structure, CSS adds styling, and JavaScript adds interactivity.

## Conclusion

HTML is the first and most important step in web development. After learning HTML, you can learn CSS to design web pages and JavaScript to make them interactive.
