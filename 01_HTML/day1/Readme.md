# Introduction to HTML

HTML stands for **HyperText Markup Language**. It is the basic building block of every website. HTML is used to create the structure of a web page, such as headings, paragraphs, links, images, lists, tables, and forms.

## Brief History of HTML

HTML was created by **Tim Berners-Lee** in 1991. It was first used to share documents on the World Wide Web. Over time, HTML improved with new versions. Today, **HTML5** is the modern version and supports audio, video, forms, graphics, and better web page structure.

## Why HTML is Useful

- It helps create the structure of websites.
- It works together with CSS for styling.
- It works with JavaScript to make websites interactive.
- It is easy to learn and important for web development.
- It is used in almost every website on the internet.

## Common HTML Tags

Some useful HTML tags are:

- `<h1>` to `<h6>` for headings
- `<p>` for paragraphs
- `<a>` for links
- `<img>` for images
- `<ul>` and `<ol>` for lists
- `<table>` for tables
- `<form>` for forms

## Conclusion

HTML is the first step in learning web development. Once you understand HTML, you can use CSS and JavaScript to build beautiful and interactive websites.
