Lets Learn About Colors

Color can be represented in:

  1. Named Colors: CSS provides a set of predefined color names, e.g., red, blue, green.
  2. Hexadecimal: A six-digit code that represents colors in the RGB color model, e.g., #FF5733.
  3. RGB: A color model that uses red, green, and blue components, e.g., rgb(255, 87, 51).
  4. RGBA: Similar to RGB but includes an alpha channel for transparency, e.g., rgba(255, 87, 51, 0.5).
  5. HSL: A color model based on hue, saturation, and lightness, e.g., hsl(9, 100%, 60%).
  6. HSLA: Similar to HSL but includes an alpha channel for transparency, e.g., hsla(9, 100%, 60%, 0.5).
